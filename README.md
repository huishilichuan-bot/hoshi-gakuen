# ほしの学園

小1〜中3の「算数・数学／国語／生活／理科／社会／英語」を、短いステップで学ぶ無料の学習アプリ（PWA）。iPhone・iPad の Safari で開いて「ホーム画面に追加」すると、アプリのように使えます。オフラインでも動きます。

- 教科 → 学年 → 単元 → ステップ → 問題。1ステップは約7分。ステップの中でも、単元の中でも、やさしい → むずかしい。
- すべての問題に解説。正解は大きな⭕とピコーン音。まちがえたら正解と解説。
- 6割以上（切り上げ）で⭐1こ＋ガチャ1回。6割未満はまちがえた問題だけやり直して、合わせて6割になった時点で⭐。⭐は減らない。1秒以内の回答は「ちゃんと読んでね」で止める。
- ⭐は毎日リセット。その日に⭐4こでゲームがひらく。ゲームでのごほうび・有利はなし。
- なかまガチャ（40種・7レア度・確率表示）。ごほうびは見た目だけ。課金なし。
- 「この問題おかしい？」の報告は端末内に保存、設定から一覧・書き出し。

## 開発

```
node tools/verify.js 40     # 問題の自動検証（算数・数学は独立した有理数計算で答えを再計算）
python3 -m http.server 8080 # ローカルで確認
```

データは localStorage（キー `hoshigakuen`、schema 1）に保存。サービスワーカーのキャッシュ名は `hoshi-gakuen-v1.7.0`。




## v1.7.0 の主な変更

ゲーム一覧を整理し、似たしくみのゲームは1つの入口にまとめて種目から選ぶようにした。もともと遊べるゲームはすべて残し、記録も各ゲームの id のまま。3Dレースの共通の土台（コースのスプライン、車両の物理、CPU対戦、ラップと順位、ミニマップ、タッチ操作）と演出キットを追加し、最初の3Dレースとして「カート」（ドリフト、ミニターボ、アイテム）を入れた。Three.js はアプリに同梱し、カートを開いたときだけ読み込む。ゲームでのごほうび・有利はこれまでどおりなし。

## v1.6.0 の主な変更

中学の中間テスト・期末テストに合わせた、100点満点の問題用紙を追加しました。3学期制（1学期中間〜3学期期末）と前期・後期の2学期制の両方で、学年・教科ごとの典型的な範囲をプリセットとして用意しています。範囲は自分で編集できます。主要5教科は50分・5大問・26問、実技教科は30分・3大問・20問（期末のみのプリセット）。結果には教科の点数、5教科・9教科の合計、大問別の得点、まちがえた問題の復習リンク、履歴と点数の推移グラフが出ます。第2回のテスト登録・計画・カウントダウンともつながります。

## v1.5.0 の主な変更

中学（中1〜中3）に、技術・家庭・音楽・美術・保健体育の5教科を追加した。内容は文部科学省の中学校学習指導要領（平成29年告示）に沿う。指導要領が学年をまとめている部分は、一般的な教科書の順番で学年に割り振った。既存の学ぶ画面、ステップ合格、単元の✅△❌、復習・予習・テスト対策、カラーテスト、すがたの進化（50単元ごと）に、そのまま組み込まれる。既存ユーザーの保存データ（schema 1）は壊さない。

## v1.4.0 の主な変更
- **カラーテスト**（中学の各教科・単元）：表と裏の2面、100点満点。おもて 10問（各5点）＝50点、うら 5問（各10点）＝50点。小学校のカラーテスト風の紙のデザインで、配点・赤ペンの丸付け・90点以上は花丸。問題はアプリの既存データから作る（市販テストのコピーや社名は使わない）。
- **漢字50問**（中1〜中3）：読み25問＋書き25問、各2点で100点満点。書きは指で書いたあと、答えを見て自分で ⭕❌。まちがえた漢字はやり直しリストへ。漢字の範囲は、アプリ既存の常用漢字（中1 362字・中2 356字・中3 288字）。
- 点数・問題数・判定は固定ではっきり表示。カラーテストと漢字の点数も ✅ 90点以上／△ 60〜89点／❌ 59点以下。
- 報酬：その単元（カラーテスト）または学年とメニュー（漢字）につき1日1回、正解1問あたり 10コインと仲良し度（いつもと同じ）。⭐・ステップ合格・すがたの進化には使わない。ステップ練習の ✅△❌ は今までどおり別表示。
- 第2回の小さな直し：予習カードの長い単元名は2行まで、単元のようすは ❌ を先に表示、ずかんの先生用段階名が収まるようにする、「Lv◯で無料」バッジがずかん見出しに重ならないようにする。

## v1.3.0 の主な変更
- ホームに **復習・予習・テスト対策** の3モード。
- **復習**：まちがえた問題ボックスと、△・❌の単元を優先して出す。
- **予習**：学年の教科書の順で、まだやっていない次の単元を出す。
- **テスト対策**：テストの日付と範囲（教科・単元）を登録。残り日数で毎日の計画を自動作成し、ホームにカウントダウンを出す。範囲からの模擬テスト（10問）も作れる。模擬テストはステップの合格や⭐・すがたの進化には使わない。
- 単元ごとの **✅△❌** 表示。判定は固定：正答率 90%以上 ✅、60〜89% △、59%以下 ❌（まだやっていない単元は「まだ」）。学ぶの単元一覧と「単元のようす」にも同じ基準を示す。
- 既存の問題データ、コイン、仲良し度、すがたの進化（50単元クリアごと）はそのまま。既存ユーザーの記録は壊さない（`tests` 配列を追加するだけ）。

## ほしまなびから引きついだ機能（旧ドキュメントの v1.4.0）
- 記録は「アカウント」が本物：ログインするとクラウド（users/{uid}）の記録を読みこんで使う。どの端末でも同じ⭐・なかま・進みぐあい
- ログアウトすると、その端末からアカウントの記録とログイン状態を消して、ログイン画面にもどる。端末の記録はゲスト用とアカウント用（uid ごと）に分けて保存
- 新しいアカウント（クラウドがからっぽ）のときだけ「ゲストの記録を引きつぐ？」と聞く。記録のあるアカウントにはゲストの記録を混ぜない
- iPhone と iPad で同時にログインOK：onSnapshot でほかの端末の変更を自動で反映。書くときはトランザクションでクラウドの最新と合わせる（⭐はへらない・なかまは両方・進みは大きい方・クリアした問題は印で同期）
- Google ログインはポップアップ（Firebase 推奨。Safari のサードパーティ保存ブロックの影響なし）。エラーはやさしい日本語の案内に
- v1.3.1 の書きこみ削減ルールはそのまま

## ほしまなびから引きついだ機能（旧ドキュメントの v1.3.0）
- アカウント（Firebase・無料の Spark プランのみ）：Googleで続ける／メールアドレス（新規登録・ログイン・パスワード再設定）／あとで（ゲスト）
- 記録をクラウド（Firestore users/{uid}）に保存して、ほかの端末でもつづきから。はじめてのログインでは端末の記録とクラウドの記録を合わせる（⭐は多い方、なかまは両方）
- クラウドへの書きこみは、ステップの終わり・アプリをかくした／とじたとき・ガチャやボス勝利のあと（3分以内はまとめる）だけ。内容が同じなら書かない（v1.3.1）。オフラインでもOK
- マイページ：アカウント欄（メール・同期状態・今すぐ保存・ログアウト・アカウント削除）
- privacy.html（プライバシーポリシー）・terms.html（利用規約）、firestore.rules（本人だけ読み書き・運営者だけ全員を読める）
- admin.html（運営者の管理画面：利用のようす。運営者の Google アカウントだけ）。テスト：tools/test_rules.js（ルール）・tools/test_admin.py（管理画面、Firebase エミュレーター）
- 設定は firebase-config.js（enabled:false でログイン機能を止められる）
