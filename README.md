# ほしの学園

小1〜中3の「算数・数学／国語／生活／理科／社会／英語」を、短いステップで学ぶ無料の学習アプリ（PWA）。iPhone・iPad の Safari で開いて「ホーム画面に追加」すると、アプリのように使えます。オフラインでも動きます。

- 教科 → 学年 → 単元 → ステップ → 問題。1ステップは約7分。ステップの中でも、単元の中でも、やさしい → むずかしい。
- すべての問題に解説。正解は大きな⭕とピコーン音。まちがえたら正解と解説。
- 6割以上（切り上げ）で⭐1こ＋ガチャ1回。6割未満はまちがえた問題だけやり直して、合わせて6割になった時点で⭐。⭐は減らない。1秒以内の回答は「ちゃんと読んでね」で止める。
- ⭐は毎日リセット。その日に⭐4こでゲームがひらく。ゲームでのごほうび・有利はなし。
- なかまガチャ（40種・7レア度・確率表示）。ごほうびは見た目だけ。課金なし。
- 「この問題おかしい？」の報告は端末内に保存、設定から一覧・書き出し。

## 開発

```
node tools/verify.js 40     # 問題の自動検証（算数・数学は独立した有理数計算で答えを再計算）
python3 -m http.server 8080 # ローカルで確認
```

データは localStorage（キー `hoshigakuen`、schema 1）に保存。サービスワーカーのキャッシュ名は `hoshi-gakuen-v1.8.0`。

## v1.7.3 の主な変更

漢字テストを、学年・学期・回ごとの固定テストに作りなおした（ホーム「漢字テスト」）。
- **小1〜小6**：1回 50 問。書き 40 問を先に、そのあと読み 10 問（まぜない）。各 2 点で 100 点満点。**中1〜中3**：1回 70 問（書き 56 → 読み 14）。**100 点への換算は「正解数 ÷ 問題数 × 100 を四捨五入」**（70 問ぜんぶ正解で 100 点、63 問で 90 点）。✅ 90 点以上／△ 60〜89／❌ 59 以下は換算後の点数で決める。
- **回数**：小1 3回（1・2・3学期に1回ずつ）、小2・小3・小5・小6 4回（1学期1／2学期2／3学期1）、小4 5回（1学期2／2学期2／3学期1）、中1〜中3 各6回（各学期2回）。ほかに最後の「中学のまとめ」（中1〜中3の18回の範囲からまんべんなく70問）。
- 学年の漢字は出てくる多さ順のまま回ごとに均等にわける。範囲の漢字は**1回に必ずぜんぶ出る**。範囲が問題数より少ない回は、同じ字の別のことば・別の読み（音読み／訓読み）で 50 問・70 問にそろえる。同じことばは1回の中で1度だけ。
- 同じ回はいつも同じ漢字・ことば・えらびかた（シードで固定）。学期・回ごとにベストと前回の点数・✅△❌を記録（`kjTerm`。保存の schema は 1 のまま。端末どうしの合流は、ベストは大きい方）。
- 中学の常用漢字を 1,110 字（各学年 370 字）にそろえるため、足りなかった 104 字（中1 8・中2 14・中3 82）に、ことばと読みを手で付けて足した。足した字は各学年の最後に並べ、今までの単元の分け方と記録は変わらない。
- 書きは今までどおり指で書いて自分で ⭕❌。コインは正解1問 10 コイン・1日1回で、すがたの進化には使わない。読み・書きのれんしゅうと「やり直しリスト」は小1〜中3で使える。
- テスト：`node tools/test_kjterm.js`（範囲の漢字がぜんぶ出る・ことばのかぶりなし・書き→読みの順・毎回同じ・点数の換算）、`tools/test_buttons.py`。

## ほしまなびから引きついだ機能（旧ドキュメントの v1.4.0）
- 記録は「アカウント」が本物：ログインするとクラウド（users/{uid}）の記録を読みこんで使う。どの端末でも同じ⭐・なかま・進みぐあい
- ログアウトすると、その端末からアカウントの記録とログイン状態を消して、ログイン画面にもどる。端末の記録はゲスト用とアカウント用（uid ごと）に分けて保存
- 新しいアカウント（クラウドがからっぽ）のときだけ「ゲストの記録を引きつぐ？」と聞く。記録のあるアカウントにはゲストの記録を混ぜない
- iPhone と iPad で同時にログインOK：onSnapshot でほかの端末の変更を自動で反映。書くときはトランザクションでクラウドの最新と合わせる（⭐はへらない・なかまは両方・進みは大きい方・クリアした問題は印で同期）
- Google ログインはポップアップ（Firebase 推奨。Safari のサードパーティ保存ブロックの影響なし）。エラーはやさしい日本語の案内に
- v1.3.1 の書きこみ削減ルールはそのまま
